# anthropic-homework
Turning Claude Code's GitHub backlog into signal for product teams.

When organizations don't manage what they learn, knowledge leaks. Teams repeat research, miss prior insights, and make decisions without context. Building the systems to prevent that is as much a product ops responsibility as a research ops one.

Equally, how quickly a team triages priority bugs and customer-reported issues reflects company culture — whether users feel heard and valued for the time they spend flagging problems. Our processes should reflect that.

This repository fetches issues from a public GitHub repository and categorizes them — using Jupyter notebooks — to help teams quickly surface signal from the noise.

For a walkthrough of the workflow — what's automated, what's human, and how the pieces fit together — see [Process.md](Process.md).
